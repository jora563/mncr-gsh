# AI-Omni UI

Веб-приложение для управления LLM-проектами и ботами в мессенджерах (Telegram, VK, Max). 

## Функционал

### Админ-панель
- Управление проектами и группами проектов
- Управление ботами
- Загрузка баз знаний, датасетов и вопросов для обучения моделей
- Запуск и мониторинг обучения LLM-моделей

### Панель оператора
- Получение чатов из очереди
- Общение с клиентами в реальном времени через WebSocket
- Закрытие и восстановление чатов
- Управление статусом оператора (онлайн/оффлайн)

### Общие возможности
- Аутентификация через Keycloak (OAuth2)
- Ролевой доступ (admin, operator)
- Поддержка светлой и тёмной тем
- Уведомления (toast)
- Проверка статуса API

## Технологии

- **Frontend**: React 18, Vite
- **Маршрутизация:** React Router
- **Аутентификация**: Keycloak (OAuth2 Authorization Code Flow)
- **WebSocket**: Нативный WebSocket API
- **Сборка**: Vite
- **Линтинг**: ESLint

## Требования

- **Node.js** версии 18.0 или выше
- **npm** или **yarn** для управления зависимостями
- **Keycloak** сервер для аутентификации
- **Backend API** (REST + WebSocket)

## Установка и запуск

### Node.js 24 + npm
```
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### Проверка
```
node -v
npm -v
```

### Установка пакетов-зависимостей
```
npm install
```

### Настройка переменных окружения
Создание `.env` файла, после чего в него необходимо ввести значения
```
cp .env.example .env
```

### Запуск
```
npm run dev
```
Приложение будет доступно по адресу `http://localhost:5173`

## Структура

```
├── public/             # Статические файлы
└── src/                # Исходный код приложения
    ├── api/            # Модуль взаимодействия с Backend API
    ├── assets/         # Статические ресурсы
    ├── components/     # Переиспользуемые UI-компоненты
    │   ├── chat/       # Компоненты операторского чата
    │   ├── dashboard/  # Компоненты дашборда админки
    │   ├── forms/      # Компоненты форм (поля ввода)
    │   ├── modals/     # Модальные окна
    │   ├── table/      # Компоненты таблиц данных
    │   └── icons.jsx   # SVG-иконки как React-компоненты
    ├── features/       # Бизнес-логика по функциональным модулям
    │   ├── bots/       # Управление ботами
    │   ├── groups/     # Управление группами проектов
    │   └── projects/   # Управление проектами
    ├── hooks/          # Кастомные React-хуки
    ├── pages/          # Страницы приложения (роуты)
    ├── providers/      # React Context провайдеры
    │   ├── theme/      # Управление темой (светлая/тёмная)
    │   └── toast/      # Система уведомлений
    ├── services/       # Сервисы приложения
    ├── utils/          # Утилиты и вспомогательные функции
    ├── App.jsx         # Главный компонент приложения (роутинг)
    ├── constants.js    # Глобальные константы
    ├── main.jsx        # Точка входа React
    └── styles.css      # Глобальные стили
```
